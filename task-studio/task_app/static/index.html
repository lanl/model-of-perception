Add your own data or colormap

Scalar dataset

CSV matrix without a header, or NPY. Finite square grids, 3–128 cells per side. Row 0 is at the bottom. Axes use the same extent.

Custom colormap

JSON list of hex colors or RGB/RGBA rows; RGB CSV without a header. Use 0–1 or 0–255 components and opaque colors. Colors are interpolated in order.
